## El cliente
Luis Fernando Peñata Perez, es el administrador de la cantina de los recuerdos de ella, que se encarga de administrar, repartir y distribuir de manera local bebidas alcoholicas y recreativas.

La gente del barrio, y potenciales clientes que la visitan cada dia.
